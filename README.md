# 🛒 E-Commerce Website

A modern and responsive e-commerce website built with **Next.js**. The project provides a smooth and user-friendly shopping experience with a clean interface and responsive design.

## 🚀 Features

* 🛍️ Browse and view products
* 🔍 Product search and navigation
* 🛒 Add products to cart
* 📱 Fully responsive design
* ⚡ Fast and optimized using Next.js
* 🎨 Clean and modern UI
* 📄 Product details pages

## 🛠️ Tech Stack

* **Next.js**
* **React.js**
* **JavaScript**
* **CSS**
* **HTML**

## 📂 Project Setup

Clone the repository:

```bash
git clone https://github.com/your-username/your-repository.git
```

Navigate to the project folder:

```bash
cd your-repository
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open **http://localhost:3000** in your browser.
